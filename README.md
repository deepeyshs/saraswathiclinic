# Saraswathi Clinic - Official Website

A modern, professional and fully responsive website designed for Saraswathi Clinic.

Built with React, TypeScript and Tailwind CSS for high performance and easy customization.

## Features
- Responsive design for all devices
- SEO optimized
- Fast loading & modern UI
- Easy to manage and deploy

## Deployment
Ready to deploy on Netlify / Vercel.

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```shone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
